قم ببناء هذه الواجهات الخاصه بمشروع نظام الكشف المبكر عن الحرائق بالرؤية الحاسوبية في المستودعات عالية السقف
 ليس كتطبيق موبايل وانما نظام web application 
1. واجهة تسجيل الدخول (Login Interface)
•	الوظائف:
o	إدخال بيانات اعتماد المستخدم. 
o	التحقق من بيانات الدخول وصحة الاعتماد. 
o	تحديد دور المستخدم والصلاحيات المرتبطة به (مدير Admin أو مشرف Supervisor) (حسب المتطلب 3.4.14 والمرحلة الأولى).
o	عرض رسالة خطأ في حال كانت البيانات غير صحيحة. 
o	توجيه المستخدم إلى اللوحة المناسبة (عرض صفحة إدارة الكاميرات أو لوحة الحوادث) بناءً على دوره. 
o	تسجيل الخروج. 
2. واجهة إدارة المستخدمين والصلاحيات (User Management Interface) - خاصة بمدير النظام
•	الوظائف:
o	إدارة المستخدمين بشكل عام. 
o	إضافة مستخدم جديد. 
o	تعديل بيانات مستخدم. 
o	حذف مستخدم. 
o	تحديد الصلاحيات للمستخدمين (الفصل بين المشرف ومدير النظام) (حسب المتطلب 3.4.14). 
3. واجهة إدارة وإعداد الكاميرات (Camera Management Interface) - خاصة بمدير النظام
•	الوظائف:
o	عرض صفحة إدارة الكاميرات. 
o	إضافة كاميرا جديدة. 
o	إدخال أو تعديل بيانات واتصال الكاميرا (حسب المتطلب 3.4.1). 
o	إدارة إعدادات الكاميرا. 
o	حذف كاميرا عند الحاجة. 
o	حفظ بيانات الكاميرا وتحديث حالتها. 
4. واجهة تحديد منطقة الاهتمام (ROI Configuration Interface) - خاصة بمدير النظام
•	الوظائف:
o	عرض صورة الكاميرا لتحديد منطقة الاهتمام (ROI). 
o	رسم نطاق مخصص للمراقبة وتجاهل الأجزاء الخارجة عنه (حسب المتطلب 3.4.4).
o	تعديل المنطقة المحددة وحفظ منطقة الاهتمام وحفظ الإعدادات (حسب المتطلب 3.4.4). 
5. واجهة لوحة المراقبة الحية (Live Monitoring Dashboard)
•	الوظائف:
o	استقبال البث المرئي ومراقبة البث المباشر (حسب المتطلب 3.4.2). 
o	متابعة وعرض حالة الكاميرات (متصلة/منقطعة) (حسب المتطلب 3.4.3). 
o	عرض تنبيه انقطاع الكاميرا. 
o	استعراض الحوادث النشطة. 
o	عرض الحادثة في لوحة المراقبة ومستويات خطورتها (حسب المتطلب 3.4.9). 
o	الاستمرار في المراقبة بشكل آلي. 
6. واجهة تفاصيل ومراجعة الحادثة (Incident Details & Review Interface)
•	الوظائف:
o	عرض لوحة الحوادث. 
o	عرض تفاصيل الحادثة وعرض صور الأدلة. 
o	مراجعة الحادثة. 
o	الإقرار بالحادثة. 
o	عرض خيارات تحديد حالة الحادثة (تأكيد، قيد المتابعة، معالجة) (حسب المتطلب 3.4.10). 
o	تصنيف الحادثة كإنذار خاطئ. 
o	كتابة وحفظ سبب الإنذار الخاطئ وملاحظات الرفض (حسب المتطلب 3.4.10). 
o	عرض رسالة نجاح التحديث بعد الإجراء. 
7. واجهة تهيئة التنبيهات الخارجية والإشعارات (External Notifications Setup) - خاصة بمدير النظام
(وهذه هي الواجهة التي تم استدراكها ودمجها مع المخطط رقم 6 الخاصة بإرسال التنبيهات)
•	الوظائف:
o	تهيئة قنوات الإرسال (إدخال رمز بوت تيليجرام ومراقبة اتصال وحدة الـ GSM) (حسب المتطلب 3.4.12).
o	إدخال وتحديد وتحديث أرقام هواتف ومعرفات المستخدمين المخولين باستقبال البلاغات (حسب المتطلب 3.4.12).
o	استلام التنبيهات للمستخدمين. 
o	عرض حالة إرسال التنبيه (SMS و Telegram). 
o	عرض رسالة فشل الإرسال (إذا تعذر الإرسال). 
o	عرض تنبيه انقطاع الإنترنت أثناء محاولة النظام الإرسال عبر تيليجرام.
8. واجهة سجل الحوادث / الأرشيف (Incidents Archive Interface)
•	الوظائف:
o	البحث في سجل الحوادث السابقة. 
o	تصفية الحوادث (باستخدام معايير: الكاميرا، التاريخ، مستوى الخطورة، حالة الحادثة) (حسب المتطلب 3.4.11).
o	الرجوع للحوادث واستعراض تفاصيلها وصور الأدلة المرتبطة بها (حسب المتطلب 3.4.11).
9. واجهة سجل التدقيق والإجراءات (Audit Trail / Action Log) - خاصة بمدير النظام
•	الوظائف:
o	عرض سجل الإجراءات. 
o	تسجيل وعرض العمليات المهمة للمستخدمين (تسجيل دخول، تعديل إعدادات، تحديث حالة حوادث، تأكيد/رفض البلاغات) (حسب المتطلب 3.4.13).
o	عرض بيانات السجل (هوية المستخدم، وقت التنفيذ، نوع العملية) (حسب المتطلب 3.4.13 والمرحلة السابعة والتاسعة).
