## 2. تفصيل واجهات مدير النظام (Admin)

يختص مدير النظام بالجانب **الإداري، البنيوي، وضبط التكوين (Configuration & Governance)** للنظام، وتظهر له الواجهات الآتية:

1. **واجهة تسجيل الدخول (`/login`):** الدخول بصلاحيات المسؤول وتوجيهه تلقائياً إلى لوحة التحكم الإدارية.
2. **واجهة إدارة المستخدمين والصلاحيات (`/admin/users`):** إضافة وحذف وتعديل المشرفين والمدراء وتعيين الصلاحيات.
3. **واجهة إدارة وإعداد الكاميرات (`/admin/cameras`):** ربط الكاميرات، تعديل روابط البث (RTSP/IP)، وإدارة مصادر المراقبة.
4. **واجهة تحديد منطقة الاهتمام ROI (`/admin/cameras/:id/roi`):** رسم نطاقات الكشف واستبعاد المناطق المسببة للإنذارات الكاذبة.
5. **واجهة تهيئة التنبيهات الخارجية (`/admin/notifications`):** ضبط وتفعيل قنوات تيليجرام ووحدة GSM وحفظ أرقام هواتف الطوارئ.
6. **واجهة سجل التدقيق والإجراءات (`/admin/audit`):** تتبع ومراقبة كافة العمليات المنفذة في النظام من قبل جميع المستخدمين.
7. **واجهة لوحة المراقبة وسجل الحوادث (`/admin/dashboard` & `/admin/archive`):** للاطلاع الشامل والمتابعة العامة لحالة المستودع وحالة الكاميرات.

## 3. تفصيل واجهات مشرف النظام (Supervisor)

يختص المشرف بالجانب **الميداني، التشغيلي، ومراقبة السلامة اللحظية (Operational & Tactical Monitoring)**، وتظهر له الواجهات الآتية:

1. **واجهة تسجيل الدخول (`/login`):** الدخول بصلاحية المشرف والتوجيه التلقائي إلى لوحة المراقبة الحية.
2. **واجهة لوحة المراقبة الحية (`/supervisor/dashboard`):**
   - متابعة شبكة الكاميرات الحية.
   - استقبال إشعارات انقطاع الكاميرات.
   - استعراض الحوادث المكتشفة النشطة ومستويات خطورتها فوراً.
3. **واجهة تفاصيل ومراجعة الحادثة (`/supervisor/incidents/:id`):**
   - فحص الحادثة وصور الأدلة التابعة لها في الزمن الحقيقي.
   - الإقرار بالحادثة (Acknowledge).
   - تحديث حالة الحادثة (تأكيد الخطر، قيد المتابعة، تمت المعالجة).
   - تصنيف الحادثة كإنذار خاطئ (False Alarm) مع تدوين سبب الرفض الإجباري.
4. **واجهة سجل الحوادث / الأرشيف (`/supervisor/archive`):**
   - البحث والتصفية واستعراض الحوادث السابقة وأدلتها لتقييم الحالات ومراجعة الإجراءات السابقة.

## 4. ملخص الربط مع مخططات الـ Use Case و الـ Activity Diagrams

- **Use Case 1 (المدير):** يوضح ارتباط المدير حصراً بـ (إدارة المستخدمين، إدارة الكاميرات، تحديد ROI، عرض سجل الإجراءات، ومتابعة حالة الكاميرات).
- **Use Case 2 (المشرف):** يوضح ارتباط المشرف بـ (مراقبة البث المباشر، استعراض الحوادث النشطة، مراجعة الحادثة وتفاصيلها، الإقرار، تصنيف الإنذار الخاطئ وتدوين السبب، البحث في سجل الحوادث، واستلام التنبيهات).
- **Activity Diagram 3:** يثبت خطوات تفاعل المدير مع واجهة إدارة الكاميرات وتحديد منطقة الاهتمام (ROI).
- **Activity Diagram 4:** يوضح تفاعل واجهة المراقبة الحية مع الخادم في بث الفيديو وتنبيهات انقطاع الكاميرا وتأكيد الكشف ومستويات الخطورة.
- **Activity Diagram 5:** يثبت مسار عمل المشرف في واجهة مراجعة الحادثة وتحديث حالتها أو كتابة سبب الإنذار الخاطئ وحفظه في سجل العمليات.
- **Activity Diagram 6:** يوضح معمارية إرسال التنبيهات عبر تيليجرام وشريحة GSM وحالات فشل الإرسال وانقطاع الإنترنت.
